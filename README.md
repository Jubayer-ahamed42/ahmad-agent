# পার্সোনাল এক্সিকিউটিভ এআই সহকারী (Agent 1)

আপনার কম্পিউটার এবং মোবাইল থেকে পরিচালনার জন্য তৈরি একটি শক্তিশালী ব্যক্তিগত এআই সহকারী।

---

## 📂 ফাইল স্ট্রাকচার
- `src/index.js` - মূল সার্ভিস ও কন্ট্রোল সেন্টার
- `src/telegramBot.js` - মোবাইল থেকে পিসি কন্ট্রোল করার টেলিগ্রাম বট
- `src/systemController.js` - পিসির স্ক্রিনশট, স্ট্যাটাস, স্লিপ ও শাটডাউন কন্ট্রোলার
- `src/scheduler.js` - সকাল ৬:০০ টার মর্নিং ব্রিফিং এবং রাত ৯:০০ টার নাইট সামারি শিডিউলার
- `src/fileSearch.js` - কম্পিউটার থেকে যেকোনো ফাইল খোঁজার ইঞ্জিন
- `src/whatsappBot.js` - হোয়াটসঅ্যাপে কাস্টমারদের সম্মানজনক অটো-রেসপন্ডার
- `src/backup.js` - প্রতি রাতে স্বয়ংক্রিয় ব্যাকআপ তৈরি
- `rules/persona.json` - এজেন্টের আচরণবিধি ও শিষ্টাচার রুলস
- `.env` - গোপন এপিআই কি ও বট টোকেন (গিটহাবে আপলোড হবে না)

---

## 🛠️ ব্যবহারের নিয়ম

### ১. সার্ভিস চালু করা:
টার্মিনালে লিখুন:
```bash
npm start
```

### ২. টেলিগ্রাম বট কানেক্ট করা:
1. টেলিগ্রামে `@BotFather` এ গিয়ে `/newbot` লিখে একটি ফ্রি বট তৈরি করুন।
2. প্রাপ্ত টোকেনটি `.env` ফাইলের `TELEGRAM_BOT_TOKEN=` এ বসিয়ে দিন।
3. আপনার টেলিগ্রামে গিয়ে বটটিকে `/start` দিলেই পিসি আপনার মোবাইলের সাথে যুক্ত হয়ে যাবে!

---

## 📱 টেলিগ্রাম কমান্ড তালিকা
- `/status` - কম্পিউটারের বর্তমান হার্ডওয়্যার অবস্থা দেখা
- `/screen` - কম্পিউটারের লাইভ স্ক্রিনশট দেখা
- `/search <ফাইলের নাম>` - কম্পিউটারের যেকোনো ড্রাইভ থেকে ফাইল খোঁজা
- `/sleep` - কম্পিউটারকে স্লিপ মোডে পাঠানো
- `/shutdown` - নিরাপদ ২FA কনফার্মেশন সহ কম্পিউটার শাটডাউন
- `/briefing` - সকাল ৬:০০ টার মর্নিং ব্রিফিং তাৎক্ষণিক দেখা
- `/summary` - রাত ৯:০০ টার নাইট সামারি দেখা
