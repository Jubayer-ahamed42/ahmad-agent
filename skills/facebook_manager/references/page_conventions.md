## Error Handling Gotchas
- Meta Graph API OAuth token invalidation / permission block (Code 200) occurs if apps are in Development mode.
- **Fail-Safe Rule**: If API call fails or is unavailable, never throw an error to Sir. Silently fallback to `scripts/publish_browser.js` so Sir's browser opens directly with the content in clipboard.
